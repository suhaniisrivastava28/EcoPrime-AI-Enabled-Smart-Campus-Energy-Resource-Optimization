# EcoPrime: AI-Enabled Campus Sustainability Prototype | GNIOT

Interactive single-page web dashboard prototype developed for **Greater Noida Institute of Technology (GNIOT)** by **Team Project Prime**.

## 🌿 Theme & Color Palette
- **Dark Forest Green**: `#0F4C3A`
- **Sage Green**: `#8FBC8F`
- **Background**: Soft Gray `#F4F7F5`
- **Surface**: Crisp White Cards with subtle elevations

## 🚀 Live Demo Features Included
1. **Top Header Bar**:
   - Title: `EcoPrime: AI-Enabled Campus Sustainability Prototype | GNIOT`
   - Team Badge: `Team Project Prime`
   - **Interactive Mode Toggle Switch**: Weekday Class Mode vs. Weekend Idle Mode.
2. **Top 4 KPI Summary Cards**:
   - **Daily Idle Energy Saved**: `384.2 kWh` (Weekday) / `429.5 kWh` (Weekend) + dynamic incremental savings.
   - **Daily Carbon Abated**: `315.0 kg CO2e` (Weekday) / `352.0 kg CO2e` (Weekend).
   - **Main Water Flow Rate**: `480 L/hr - Normal`, changes dynamically to red `32,500 L/hr - RUPTURE ALERT`.
   - **AI Occupancy Accuracy**: `99.6% | Timetable Synced`.
3. **Interactive Lecture Wing Control Panel (Left)**:
   - 4 Rooms:
     - `Block A - Room 101`
     - `Block A - Room 102`
     - `Block B - Lab 204`
     - `Block C - Hall 301`
   - Real-time display for: PIR Sensor Status, Timetable Status, AI 30-Min Occupancy Prediction %, and Relay State.
   - **Faculty Manual Override** toggle button for each room (forces power ON and logs action).
4. **AI Simulation & Anomaly Controls (Right)**:
   - **Simulate 15-Min Vacancy Cutoff**: Auto-switches empty rooms to `AUTO CUTOFF` and increments saved kWh.
   - **Simulate Plumbing Pipe Leak**: Triggers red emergency banner and 32,500 L/hr hydraulic surge alert.
   - **Reset System Baseline**: Restores normal operating parameters.
   - **AI Decision & ESG Audit Log**: Real-time auto-scrolling log with timestamps and categorized badges.
